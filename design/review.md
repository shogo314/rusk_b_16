# 未決定事項の一覧

[設計ノートの入口](README.md)

現在の機能と未実装の方針を組み合わせる際に、決める必要がある問いをまとめる。採用済みの仕様や次版の実装計画ではない。β11で合意した循環共有・コピーの方針は[β11の開発記録](../docs/development/beta11.md)と[共有の設計](values.md)を参照する。

| 論点 | 現在 | 今後の判断 |
|---|---|---|
| 名前探索 | ローカル関数・型、直接の引数型からの探索、包含関係による隠蔽、ジェネリックな引数数による順位 | 型による関連候補の追加規則 |
| 捕捉と再帰 | 無名関数・ローカル関数は宣言実行時のオブジェクトを共有し、再帰・相互再帰は元の環境を使用 | 再帰・循環する捕捉環境の解析精度と深い解放 |
| 権限 | readonly注釈・型表記と共有経路への伝播、外側と要素の区別、型引数は不変 | 未知の操作や再帰的な保持の解析精度 |
| 寿命 | Objと証明できた借用・値保持 | 利用者が循環を切る方式と手動コピーの共有・効果解析に対応。深い構造の解放は継続課題 |
| 走査 | has_next/nextと変更回数の検査 | Optionを返すnextへの接続、zipの終端消費、逆向き走査 |
| 配列 | Vec・Str、直接格納のIntArray・ビット列、Deque・Array、構造変更を検出するSlice | 汎用の直接格納、文字列・ビット列のビュー、readonlyな走査の解析精度 |
| 数値 | 検査付きInt・Int128、Float、BigIntと明示変換、ビット列 | 巨大整数の高速乗算、リテラルの文脈型付け、追加の数論アルゴリズム |
| 引数と推論 | 位置引数、名前付き専用引数と既定値、無名関数の引数型推論、限定した期待型伝播 | 追加の型推論の範囲 |
| 導出とキー | struct・enumのコピー・等値比較・ハッシュの自動生成、定義スコープの手動優先、独自キー | 順序比較の自動生成、キーの契約を静的に保証する範囲 |
| コンパイル時評価 | 型とInt・Bool値引数による具体化 | 一般の定数式・関数評価、副作用、資源上限 |

ローカル型の持ち出しとジェネリック探索、readonlyな要素と変更可能な外側のコンテナは、分野をまたいで設計する必要がある。

β10で採用した仕様と検証例は[ローカル関数・名前探索の仕様](local-functions.md)にある。捕捉環境の準備と持ち出しは、その仕様に従って実装・検証済みである。検証の所在は[β10の開発記録](../docs/development/beta10.md)を参照する。

LLVM、Unicode専用型、動的な共通関数型は、現在の基盤を整える前提ではない。性能改善は意味の一致と測定で確認する。文書例・examplesの追加時に検証漏れを作らないことも継続課題である。
