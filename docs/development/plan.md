## β13の区切り

β13では、実行に不要な定義を生成C++から省き、標準ライブラリAPIと命名規約を整理しました。組み込み標準ライブラリの出典は処理系の版・公開元URL・リビジョンで示し、生成C++の末尾には利用者のRuskソースを記録します。完成コミット `be310e0` のテストCIと文書CIは成功し、公開文書への反映も確認しました。

### 生成C++の出力方針

型検査と具体化の後に、トップレベルの実行処理から必要な定義をたどってC++を生成します。関数、構造体・列挙型、extern宣言、本体とABI補助コード、標準ランタイムが対象です。関数値、捕捉、型付きextern、自動導出のコピー・比較・ハッシュからの依存を保持します。未使用の定義にも型検査を行います。

点検の修正を取り込み、通常・最適化なしの回帰テストで出力と実行結果を検証します。基礎ランタイムに加え、宣言から `depends` で依存する標準ランタイム資源を出力します。暗黙のC++参照を許していた利用者のexternと、初期化を含み得る外部シンボルには従来の出力を保ちます。詳細は[externの規則](extern.md)を参照してください。

BigIntの高速乗算、追加のスライス対象、readonlyを含むネイティブ走査の解析精度は継続課題です。

### ソース記録を含む生成ファイルのサイズ

組み込み標準ライブラリの出典は処理系の版・公開元URL・リビジョンで確認できるため、生成C++のソース記録は利用者のRuskファイルに絞りました。通常モードで同じ `examples/aplusb.rusk` を変換したとき、生成ファイル全体は802,196バイトから28,761バイトに減り、そのうち利用者のソース記録は247バイトでした。[記録形式](../getting-started/cli.md)

### 標準ライブラリAPIの変更

- `MultiSet` の `m.erase(key)` は `m.erase_one(key)` に置き換えてください。同値のキーをすべて削除する場合は `m.erase_all(key)` を使います。
- `UnionFind.unite(u, v)` は併合した場合に `true` を返すようになりました。従来どおり文として呼び出せます。`Unit` を要求するコールバックに渡す場合は、`(uf: UnionFind, u: Int, v: Int) => { uf.unite(u, v); }` のように結果を捨てる関数で包んでください。
- `Vec<T>` と `Str` に `is_empty()` を追加しました。readonlyの値にも使えます。

## β15の完成範囲

β15はβ14の完成コミット `c130efc` から開始しました。読み取り専用の配列から作った遅延走査での `sum` と、読み取り専用の配列での `min`・`max`・`argmin`・`argmax` を整備します。

無名関数は、呼び出しから引数型が一意に分かる場合に型を省略できるようにします。`values.map(x => x + 1)`、`cards.sort_by_key(card => card.value)`、`values.fold(0, (acc, x) => acc + x)` と、利用者が定義したジェネリック関数からのコールバック呼び出しを検証します。型を決められないときは、型注釈が必要な引数を診断します。型を明示した場合との実行結果、捕捉・共有、readonlyの検査を通常と `--no-opt` の両方で確認します。仕様と例を更新し、完成コミットをpushしてテストCIと文書CIを確認します。

β15の完成コミットは `b2d8707` です。集計APIの修正と無名関数の引数型省略を含み、テストCIの全9ジョブと文書CIが成功しました。[テストCI](https://github.com/shogo314/rusk_b_15/actions/runs/45886520121)・[文書CI](https://github.com/shogo314/rusk_b_15/actions/runs/45886520126)
